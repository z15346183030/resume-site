# 赵旭 — 个人简历网站

我的个人简历网站，展示项目作品、技能栈、开源工具和实践经历。

## 结构

| 区块 | 内容 |
|---|---|
| 01 关于 | 定位、数据、教育背景 |
| 02 经历 | 实习与项目经历时间线（标签页切换） |
| 03 项目 | 4 个 AI 产品项目卡片 |
| 04 开源工具 | 15 个零依赖单文件工具（约 21,700 行 Python），按「读懂代码 / 文档与发布 / 数据与配置 / 上线闸门」分组 + 6 个长期项目 |
| 05 技能 | AI 应用与产品、商业与运营、数据与工具、语言 |
| 06 联系 | 发邮件菜单 |

## 特点

- 纯前端，单文件实现
- 暗色主题，现代 UI
- 响应式设计，移动端适配
- 平滑滚动导航

## 部署

### GitHub Pages
1. 推送到 GitHub 仓库
2. Settings → Pages → 选择 main 分支
3. 访问 `https://username.github.io/resume-site/`

### 本地预览
直接打开 `index.html` 即可。
